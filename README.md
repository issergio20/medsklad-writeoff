# Тестовое задание 1 — Списание материалов со склада (Product Designer)

- `docs/01-razbor-zadaniya.md` — разбор всех блоков задания, противоречия, допущения, план
- `docs/02-reshenia.md` — одностраничник решений для сдачи
- `prototype/` — интерактивные HTML-прототипы (открыть `prototype/index.html` или запустить сервер)

Запуск локального сервера (http://localhost:8765):

```
powershell -NoProfile -ExecutionPolicy Bypass -File serve.ps1
```

## Работа в VS Code

Откройте папку проекта в VS Code (`code .`). Настройки лежат в `.vscode/`:

- **F5** («Прототипы в Edge» / «Прототипы в Chrome») — запускает сервер и открывает прототипы в браузере.
- **Terminal → Run Task** — «Прототипы: запустить сервер», «Прототипы: открыть в браузере».
- При первом открытии VS Code предложит рекомендуемые расширения: Figma for VS Code, Prettier, Markdown All in One, проверку орфографии (EN + RU).
- `figma/` — состояние переноса в Figma и локальный плагин (`figma/plugin/manifest.json`) для сборки экранов в обход лимита MCP.

Следующий шаг — перенести экраны в Figma: компоненты с состояниями и пояснения рядом с экранами.
